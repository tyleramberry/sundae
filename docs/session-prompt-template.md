# Daily session-starter prompt (30-Day Sundae Challenge)

Copy this at the start of each day's session, swapping in the day number.
Everything else stays the same — project context lives in the repo now, so
you shouldn't need to repeat it.

---

I'm running the 30-Day Sundae Challenge. Read **[Day N]** in
`docs/30-Day-Calendar.md` in this repo and execute the Development tasks for
today, then guide me through the Content tasks.

For each Development task: implement it, run lint + build, and actually
verify the behavior works (spin up the dev server, drive it through the
Browser pane, hit real endpoints) — not just "it compiles" — before moving to
the next task. Commit and push working increments as you go, matching the
existing commit message style in the repo's git log.

If a step needs a human in the loop — signing into a real account, clicking
through an OAuth consent screen, a CAPTCHA, anything requiring a password or
payment — do everything around it yourself, then tell me exactly what single
action you need from me, wait for it, and continue from there without
re-explaining the whole task. Don't stop and ask for anything that doesn't
actually require it.

If a Development task involves spending money (Meta Ads, paid API tier,
domain purchase, etc.), stop and confirm with me first instead of doing it.

After Development is done, walk me through the Content tasks for today —
I'll handle actually posting/filming those myself, just tell me what to
capture and give me a draft caption.
